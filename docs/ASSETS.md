## Sounds, music and icons

Sounds and music are synthesised by the repository's scripts, from fixed seeds and using only the Python standard library (no samples, no network). They are encoded to Ogg Vorbis with `ffmpeg` (libvorbis). Running the scripts again produces the same bytes.

| Files | Source | Licence | Use |
|---|---|---|---|
| `res/raw/sfx_*.ogg` | `tools/generate_sounds.py` (`audio_dsp.py`) | MIT, like the rest of the repository | Effects: shots, impacts, sinkings, special weapons, clock tick |
| `res/raw/music_*.ogg` | `tools/generate_music.py` (`audio_dsp.py`) | MIT, like the rest of the repository | Home music (`music_home`) and one track per sea (`music_sea01`…`music_sea12`), looping seamlessly |

The committed files are the ones that ship in the APK. The build does not regenerate them.

## Icon and store images

The icons and store images are drawn in code and generated by `tools/render_icon.py`. The script uses no external libraries (only the Python standard library), so the output is reproducible: running it twice gives PNG files with the same bytes (checked with `sha256sum`).

| File | Size | Use |
|---|---|---|
| `app/src/main/res/drawable/ic_launcher_background.xml` | vector 108×108 dp | Background layer of the adaptive icon: #0B1528 with heading lines at 10 % opacity |
| `app/src/main/res/drawable/ic_launcher_foreground.xml` | vector 108×108 dp | Foreground layer: a brass compass rose (#E0B154, points alternating with #A97C2E) and a wax seal (#D2493A, ring #8E2A20) in the upper right quadrant. Everything inside the 66 dp safe zone |
| `app/src/main/res/drawable/ic_launcher_monochrome.xml` | vector 108×108 dp | Monochrome layer (Android 13 and later): silhouette of the rose and the seal, one colour |
| `fastlane/metadata/android/{en-US,pt-PT}/images/icon.png` | 512×512 RGB | Store icon (F-Droid). Background and foreground composited, no mask |
| `fastlane/metadata/android/{en-US,pt-PT}/images/featureGraphic.png` | 1024×500 RGB | Store feature graphic, no text: compass rose, heading lines, chart grid and four seals |

The PNG files are identical in both languages, because the icon and the feature graphic contain no text.

How the script works:

- The geometry (polygons in 108-unit coordinates) is defined once in the script. The vectors and the PNG files come from the same geometry, with coordinates rounded to two decimal places before any use.
- Filling uses scanlines with the even-odd rule and 4×4 subsamples per pixel (antialiasing). Compositing is "over" in premultiplied RGBA.
- PNG files are written with `zlib` at level 9, without date or metadata.

To regenerate: `python3 tools/render_icon.py` (from the repository root or from any folder). Do not edit the XML or PNG files by hand: change the geometry or colours in `tools/render_icon.py` and run the script.
