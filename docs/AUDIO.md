# Night Fleet: sound, music and vibration

All of the game's audio is **generated by the repository's scripts** (licence **MIT**, the same as the code). There are no samples, recordings or third-party sounds. The generated files are committed in `app/src/main/res/raw/` and are what ships in the APK: the build does not regenerate them.

## Parameters

Effects (`tools/generate_sounds.py`):

- Sample rate 44,100 Hz, mono, 16 bit, peak-normalised to −3 dBFS.
- Each effect has its own seed: `zlib.crc32(name)`, never `hash()`, which is not stable between runs.
- 3 ms fade-in and 15 ms fade-out on all effects, so there are no clicks.
- Length limits: 2.5 s, or 3.5 s for the victory sound.
- Synthesis: sines with exponential glissando, filtered noise (one-pole filters), exponential envelopes and inharmonic partials (bells and metal).

Music (`tools/generate_music.py`, with the shared `tools/audio_dsp.py`):

- 32,000 Hz, mono, peak-normalised to −6 dBFS.
- Seeds and scales are in the `TRACKS` table: each track has its own seed, duration (64–86 s), tonic (MIDI), scale, chord sequence and layers (pads, drone, bells, pizzicato, marimba, flute, pulse, drums, bass, particles, thunder, shimmer).
- Scales: major, major and minor pentatonic, Dorian, Phrygian, Lydian, Mixolydian, Aeolian and Locrian.
- Pads: two detuned sines and one octave harmonic, under a sin² window; chords overlap by half a step.
- Seamless loop: each track is rendered for `duration + 4 s`, and the last 4 s are mixed into the start with a constant-power curve (`sin`/`cos`). The end continues into the start.
- Notes, bells and beats are pre-rendered and cached by their parameters, which keeps generation at about 1 minute for the 13 tracks.

Encoding (both scripts):

- `ffmpeg` with `libvorbis`, quality `-q:a 3`. Metadata is stripped (`-map_metadata -1`, empty `encoder=` in the stream), and `+bitexact` is set on the stream and the container, so the output does not depend on the run.
- Tool version used for this release: ffmpeg n9.0.2 (libvorbis).

## How to regenerate

```sh
python3 tools/generate_sounds.py          # the 16 sfx_*.ogg files
python3 tools/generate_music.py          # the 13 music_*.ogg files
python3 tools/generate_music.py --only music_sea11   # one track
python3 tools/generate_sounds.py --wav-dir DIR       # also keeps the intermediate WAV files
```

Requires Python 3 (standard library only) and `ffmpeg` with `libvorbis` (`ffmpeg -encoders | grep libvorbis`). For another ffmpeg, set `FFMPEG=/path/to/ffmpeg`.

## Reproducibility

Running both scripts twice in a row gives identical SHA-256 hashes for the `.ogg` files (29 of 29), and also for the intermediate WAV files (29 of 29). If a file changes, a parameter or the generator changed: in that case, regenerate and commit everything in the same commit.

## Use in the code

- `SoundEffect` (enum with `R.raw.sfx_*` and a relative `gain`) and `SoundPlayer` (4-voice SoundPool, lazy loading, at most one identical sound every 50 ms).
- `MusicTrack` (enum with `R.raw.music_*`) and `MusicPlayer` (looping MediaPlayer, 600 ms crossfade, default volume 0.4, audio focus with ducking, `pause()`/`resume()` for onStop/onStart).
- `Haptics` and `HapticPattern`: hit 25 ms; sinking 40-60-80 ms; own ship hit 60 ms; mine 2 × 30 ms.
- `AudioSettings` (data) and `GameAudio` (connects the three to the same state and exposes `setSfxVolume`, `setMusicVolume`, `setVibration`).
